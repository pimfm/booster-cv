# booster-cv

A playful CV: a sealed booster box you open; the cards are Pim.

```
npm install
npm run dev        # http://localhost:5173
npm run check      # typecheck, lint, unit tests, content validation
npm run e2e        # Playwright (run `npx playwright install` once)
```

Content lives in `/content` — see `docs/CONTENT-AUTHORING.md`. Plan and specs: `docs/PLAN.md`.
