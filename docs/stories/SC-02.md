# SC-02 — Integration

**Phase** 2 · **Size** M · **Depends on** BX-02, PK-03, CR-03, BN-02 (BN-03, CR-04 preferably merged too)

## Goal
The four lanes become one experience: pack-complete, all-collected, reset, z-order, `layoutId` handoffs, and every `## Requests` item from lane PRs resolved. Spec: INTERACTION-SPEC §6–§8.

## Owns
`src/app/App.tsx`, `src/scene/PackComplete.tsx`, `src/chrome/ResetConfirm.tsx`, `src/chrome/Header.tsx` (reset control), `src/scene/AllCollected.tsx`, plus any file named in a resolved Request (list them in the PR).

## Scope
- Final composition and z-order per INTERACTION-SPEC §0; verify every `layoutId` handoff: pack shelf → focused; stage → detail; stage/detail → binder slot.
- `PackComplete`: glyph + strings.pack_done, 900 ms interruptible timer → `DISMISS_PACK`; any click/key dismisses early.
- `AllCollected`: stamp on tray, strings.all_done, hook for CT-04 contact card (renders `StageCard` with `meta.contactCard` when `phase === 'all-collected' && !collected.includes('contact')` — implement the machine side: `collected` may contain the contact id; `isComplete` counts it; **coordinate with F-04 owner or make the change here with the spec update**, since this is the integration story).
- `ResetConfirm`: inline two-button confirm; on yes: reverse fade of slots (capped 600 ms), `RESET` → `resetting` → `RESET_DONE`.
- Header: name (left), lang placeholder (PL-01), sound placeholder (PL-03), reset `IconButton`.
- Walk the AGENT-WORKFLOW §4 slot diagram and remove any remaining F-06 stubs.
- Resolve all `TODO(<ID>)` left by lanes; list each in the PR.
