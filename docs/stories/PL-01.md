# PL-01 — i18n

**Phase** 3 · **Size** M · **Depends on** F-06

## Goal
English and Dutch, both first-class, switchable in one key, with per-locale card copy.

## Owns
`src/platform/i18n/LocaleProvider.tsx`, `useLocale.ts`, `t.ts`, `plural.ts`, `src/chrome/LangToggle.tsx`, the lang section of `src/chrome/Header.tsx`.

## Scope
- `LocaleProvider`: initial locale = persisted (`booster.locale`) → `navigator.languages` (nl* → `nl`) → `en`. Sets `<html lang>`. Exposes `locale`, `setLocale`, `toggle`.
- `t(key, vars?)` with `{n}`/`{title}` interpolation and `plural.ts` for `{one, other}` objects; type-safe keys from `strings.en.ts`.
- `useLocale()` also returns `L(localized: Localized) => string` for card fields.
- `LangToggle`: segmented `EN | NL` (two `Button`s with `aria-pressed`), key `L`; switching re-renders copy in place with no animation (text swap only) — except `StageCopy` which already fades.
- Audit: every component uses `t`/`L`; `lint-tokens` extended with a rule that flags JSX text nodes with letters outside `src/dev/` (allow-list for `×`, `/`, numbers).
- Meta title/description per locale handled in PL-04; expose `locale` for it.

## Acceptance criteria
- [ ] Playwright: `?lang=nl` dev override and the toggle both switch all visible copy; `<html lang>` updates; locale persists across reload.
- [ ] Vitest: `t` interpolation, plural forms, missing key is a type error.
- [ ] Lint rule catches a planted hard-coded string (test in `scripts/lint-tokens.test.mjs`).
- [ ] Screenshots `PL-01-nl-*.png`.
