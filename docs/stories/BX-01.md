# BX-01 — Sealed box visual

**Phase** 2 · **Lane** A · **Size** M · **Depends on** SC-01

## Goal
The first thing the visitor sees. It must look like a product and like an invitation, with zero motion until touched.

## Owns
`src/scene/Box.tsx`, `Box.module.css`, `src/scene/BoxWrap.tsx`, `src/scene/BoxLid.tsx`, `src/scene/boxGeometry.ts`.

## Scope
- Box geometry: a front face (name as set name, subtitle, `n cards · m packs` from content) with `--border-3`, `--shadow-2`; a top "lid" face drawn as a separate element 14 % of the height, offset to suggest depth (flat, brutalist — a second rectangle offset up-left with a different tint, not a 3D transform).
- `BoxWrap`: translucent overlay (`paper` at 35 %, `mix-blend-mode: multiply` optional) with a diagonal seam line and a small tab (a 24×16 rectangle) top-right. Exposes CSS vars `--p` for progress (BX-02 drives it).
- Hover lift on `pointer: fine` only. Focus ring on the box as a button (`role="button"`, `aria-label` from strings.hold_box).
- Sizes: desktop 320×400, mobile `min(72vw, 300px)` wide, proportional height.
- Box is a single focusable element; `tabIndex=0`.

## Acceptance criteria
- [ ] Renders from content (`meta.setName`, counts). RTL test.
- [ ] Static screenshot matches DESIGN-BRIEF grammar; reviewer approval `BX-01-sealed-*.png`.
- [ ] No animation runs in `sealed` (Playwright: `data-animating="false"` after load).
- [ ] Touch target of the whole box; hover lift not applied on `mobile-webkit`.
