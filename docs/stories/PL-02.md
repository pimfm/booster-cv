# PL-02 — Persistence

**Phase** 3 · **Size** S · **Depends on** F-04

## Goal
Coming back keeps your binder; changing content never shows a broken binder.

## Owns
`src/platform/persistence/PersistenceProvider.tsx`, `storage.ts`, `schema.ts`.

## Scope
- Key `booster.v1`; payload `{ v: 1, contentVersion, collected, openedPacks, locale?, sound? , savedAt }`; zod-validated on read; any mismatch (schema or `contentVersion`) → discard silently and start sealed.
- Hydrate once on mount via `HYDRATE`; write on every change of `collected`/`openedPacks` (debounced 150 ms) and on `RESET` (clear).
- Private-mode / quota errors are swallowed; the app works without storage.
- Also persists card ids that no longer exist? No — filtered out on hydrate; if that leaves an opened pack partially collected, mark the pack unopened (cards would otherwise be unreachable). Unit-test this.
- Dev helper: `?fresh` clears storage; `?state=all` hydrates a complete binder (for screenshots). Dev only.

## Acceptance criteria
- [ ] Vitest: round trip, invalid JSON, old `contentVersion`, missing ids → documented outcomes.
- [ ] Playwright: collect 3 cards, reload → `box-open` with 3 in binder; reset → reload → sealed.
- [ ] No writes before hydrate (no overwrite of a saved binder with an empty one on first render — test with a pre-seeded storage).
