# PL-04 — Meta and OG image

**Phase** 3 · **Size** S · **Depends on** D-02

## Goal
A link in WhatsApp or LinkedIn looks like a sealed box with Pim's name.

## Owns
`src/platform/meta/Meta.tsx`, `src/dev/og/OgCard.tsx`, `scripts/og-render.mjs`, `public/og.png`, `public/favicon.svg`, `public/site.webmanifest`, `index.html` head.

## Scope
- `Meta`: sets `document.title` and `meta[name=description]` from `meta.og` per locale at runtime; static defaults in `index.html` (English) for crawlers; `og:title`, `og:description`, `og:image` (1200×630, absolute URL built from `VITE_SITE_URL`), `og:locale` + `og:locale:alternate`, `twitter:card=summary_large_image`, `theme-color` = paper.
- `/dev/og`: a 1200×630 composition in real tokens: the sealed box (reuse `Box` in a static variant) on paper with the set name and tagline.
- `scripts/og-render.mjs`: Playwright screenshot of `/dev/og` at 1200×630 @2x → `public/og.png`; run in CI build step so it's never stale.
- Favicon: an SVG mark (ink square with the paper initial), plus 180 px apple-touch PNG from the same script.

## Acceptance criteria
- [ ] `npm run og:render` produces `public/og.png` 2400×1260; committed version matches the current tokens (CI re-renders and `git diff --exit-code public/og.png` — allow a tolerance by comparing a perceptual hash if byte-diff is flaky).
- [ ] Head tags validated with a Vitest reading `dist/index.html` after build.
- [ ] Reviewer checks the OG image against the taste test.
