# SC-01 — Stage layout

**Phase** 2 · **Lane** A · **Size** S · **Depends on** D-03

## Goal
The responsive frame everything sits in (INTERACTION-SPEC §0), the copy line under the stage, and the real `App.tsx` composition with lane slots.

## Owns
`src/scene/Stage.tsx`, `Stage.module.css`, `src/scene/StageCopy.tsx`, `src/app/App.tsx` (until SC-02), `src/app/layout.module.css`.

## Scope
- CSS grid: header / stage / binder; desktop ≥ 900 px binder right rail 220 px; mobile bottom strip 96 px; `100dvh`, no page scroll, safe-area insets.
- Stage: cream paper, optional dot grid per chosen direction, centred content area with a max width of 1100 px, `position: relative` for absolutely positioned pieces (lid, tear strip).
- `StageCopy`: the one line of guidance under the stage object, driven by phase via a map in `src/scene/stageCopy.ts` (strings keys per INTERACTION-SPEC). Text swaps with a `dur.sm` fade; the transient `hold_not_yet` message with 1.6 s timeout lives here, triggered by a machine flag `lastHoldCancelledAt`.
- Slots per AGENT-WORKFLOW §4; stubs from F-06 remain the bodies until lanes replace them.

## Acceptance criteria
- [ ] No vertical page scroll at 390×660 (small phone) through 1920×1080; content never clipped.
- [ ] Binder region reserves space in both layouts (lane D fills it).
- [ ] `StageCopy` shows the right key per phase (RTL test over all phases) and the not-yet message appears after an early release (Playwright, using `holdMs=50`, release at 20 ms).
- [ ] Screenshots `SC-01-empty-*.png`.
