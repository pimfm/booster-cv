# D-03 — Primitive kit + `/dev/kit`

**Phase** 1 · **Size** M · **Depends on** D-02

## Goal
A small, finished set of primitives so lanes compose instead of styling.

## Owns
`src/ui/Button.tsx`, `IconButton.tsx`, `Toggle.tsx`, `Badge.tsx`, `Frame.tsx`, `Chip.tsx`, `Kbd.tsx`, `VisuallyHidden.tsx`, `SegmentBar.tsx` (10-segment stat bar), each with `.module.css`, `src/ui/index.ts`, `src/dev/kit/Kit.tsx`.

## Scope
- `Button`: variants `primary` (accent-1 fill), `secondary` (paper fill), `ghost` (no border, underline on hover); sizes `md` (44 px) and `sm` (36 px, desktop only); press behaviour = shadow collapse + translate (DESIGN-BRIEF §1); `leadingIcon`, `kbd` prop to show a `<Kbd>` hint on `pointer: fine` only.
- `IconButton`: square 44 px, `aria-label` required (type-enforced), `pressed` state for toggles.
- `Toggle`: labelled switch, brutalist (square thumb), used for sound.
- `Badge`: rarity mark component (`rarity` prop) and generic text badge.
- `Frame`: the bordered box with optional shadow level and tint; the base of cards, packs, panels.
- `Chip`: outlined tag.
- `Kbd`: keyboard hint.
- `SegmentBar`: `value 0–10`, `label`, animates fill on mount with `spring.settle` staggered 20 ms/segment; reduced → instant.
- All primitives: forward refs, accept `className`, keyboard + focus-visible styles from tokens, no copy (labels via props).
- `/dev/kit`: every primitive in every state, dark-on-tint examples, token swatch table from D-02, and the fonts.

## Acceptance criteria
- [ ] RTL tests per primitive: renders, keyboard activation, `aria-pressed`/`aria-checked` correctness.
- [ ] `IconButton` without `aria-label` is a type error (test with `// @ts-expect-error`).
- [ ] Axe (via `@axe-core/playwright`) on `/dev/kit` reports 0 violations on both projects.
- [ ] Screenshots `D-03-kit-*.png`; reviewer approval.
- [ ] Checkpoint `docs/checkpoints/M1.md`.

## Out of scope
Card component (CR-01) — it composes `Frame`, `Badge`, `SegmentBar`, `Chip`.
