# QA-01 — End-to-end journey suite

**Phase** 5 · **Size** M · **Depends on** Milestone M3 (all PL-*), SC-02

## Goal
A suite that fails when the experience breaks, not when a pixel moves.

## Owns
`e2e/journeys/*.spec.ts`, `e2e/helpers/journey.ts`, `playwright.config.ts` (projects list), `.github/workflows/ci.yml` (matrix).

## Scope
Journeys, each on `desktop-chromium`, `mobile-webkit`, `mobile-chromium` (from PL-06) and their reduced variants:
1. **Full loop**: sealed → all packs → all cards (mix of Read/Collect, swipe on mobile, keyboard-only variant on desktop) → contact card → complete → reset.
2. **Persistence**: partial progress → reload → continue → complete → reload → complete; `contentVersion` bump → sealed.
3. **Locale**: whole loop in NL; toggle mid-loop; `<html lang>` and a sampled card title per locale.
4. **Interrupts**: early release on box and pack; tab blur mid-hold; `Esc` from every closable state; binder detail from the rail and from the sheet.
5. **Sound** (chromium only): toggle on → events logged; off → none.
Use the real content (Pim's) by then; assertions reference content via the loader in test, not hard-coded titles.

## Acceptance criteria
- [ ] All journeys green in CI, total runtime < 6 min with sharding 2×.
- [ ] Flake policy: 0 retries locally, 1 retry in CI; any test needing more is fixed, not retried.
- [ ] Traces and videos uploaded on failure.
