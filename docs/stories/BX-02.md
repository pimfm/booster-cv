# BX-02 — Hold-to-unwrap and open sequence

**Phase** 2 · **Lane** A · **Size** M · **Depends on** BX-01, PK-01 (packs must exist to rise onto the shelf)

## Goal
The first satisfying moment. Spec: INTERACTION-SPEC §1.

## Owns
`src/scene/Box.tsx` (behaviour), `src/scene/useHold.ts` (shared hook, also used by PK-03 — see note), `src/scene/BoxOpenSequence.tsx`.

## Scope
- `useHold({ onStart, onEnd })`: binds `pointerdown/up/cancel/leave`, `keydown/keyup` for Space/Enter (ignore key repeat), `blur`, `visibilitychange`; dispatches `HOLD_START`/`HOLD_END`. Also sets `touch-action: none` and prevents context menu on long press (mobile!). Uses `setPointerCapture`.
- Map `holdProgress` (from machine via `select.holdVisual`) to the wrap seam opacity, box scale, tab rotation/translate using `useMotionValue` + `useTransform` (no React re-render per frame: subscribe to a motion value the Provider updates — add `holdProgressMV` to the provider in a **Request** if not present; F-04 should expose it; if it does not, implement subscription locally via `useSyncExternalStore` on a ref).
- Marks at 0.33/0.66: the 1-px shake via `animate()` on the box, and emit `hold:mark` on the audio event bus (`src/platform/audio/bus.ts` — if PL-03 hasn't landed, create a 10-line event bus in `src/platform/events.ts`; **this file is owned by SC-01's lane A, create it here**).
- Early release: relax via machine `holdDirection: 'down'`, no extra code beyond mapping.
- Open sequence as specified: wrap halves fly off (`spring.pack`, ±12°), lid lifts and rotates back with `spring.lid` (2D: translateY then rotateX around top edge with `perspective` is allowed for the lid only — it is the one element where a 3D hint is acceptable because it fades out at 80 %), packs rise with 70 ms stagger (packs render in PackShelf; coordinate through a `box-open` enter animation on `Pack` with a `custom={index}` delay — lane B exposes `PackShelf` entering variants keyed by phase), box shrinks to the tray line.
- Reduced motion: wrap/lid opacity fades `dur.sm`; packs fade in; no translation.

## Acceptance criteria
- [ ] Playwright: mouse hold, touch hold, Space hold, Enter hold all open the box on their respective projects; early release returns to `sealed` and shows `hold_not_yet`.
- [ ] Long-press on mobile shows no context menu / text selection (assert `document.getSelection()` empty and no `contextmenu` fired).
- [ ] Switching tabs mid-hold cancels (`visibilitychange` test).
- [ ] Reduced-motion project completes `openBox()` with no element translating more than 0 px (assert via `getBoundingClientRect` before/after on the lid).
- [ ] Video `BX-02-open.webm` + screenshots at p≈0.5 and after open; reviewer taste test.
- [ ] No React re-render per `HOLD_TICK` (React Profiler test or `why-did-you-render` in dev asserting ≤ 2 renders of `Box` during a hold).
