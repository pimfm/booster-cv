# CR-02 — Reveal stack, draw, stage card

**Phase** 2 · **Lane** C · **Size** M · **Depends on** CR-01

## Goal
Drawing a card feels like turning a card over on a table. Spec: INTERACTION-SPEC §3 step 3, §4.

## Owns
`src/scene/RevealStack.tsx`, `RevealStack.module.css`, `src/scene/StageCard.tsx`, `StageCard.module.css`, `src/scene/StageCardControls.tsx`, `src/scene/rarityBeats.ts`.

## Scope
- `RevealStack`: renders up to 5 `CardBack`s offset ±3 px alternating; count label `n left` (strings `cards_left` plural); enters from the pack mouth (CSS vars contract from PK-03) with 40 ms stagger, `spring.card`; `pointer-events: none` for the first 400 ms of `revealing` after a tear (not after a collect). Click/tap/Enter/Space/`→` → `DRAW_CARD`. It is one button (`aria-label` strings.tap_to_draw).
- Draw animation: the "slide-turn" — back lifts 12 px, moves toward stage centre-left, then back translates +24 px & fades (`dur.sm`) while the front enters from −24 px (`ease.out`, `dur.md`) with scale 0.96 → 1 (`spring.card`). Implement with `AnimatePresence` on `face`, keyed by card id. Stack dims to 0.5 in `card-on-stage`.
- `StageCard`: renders `Card size="stage"` for `stageCardId`, focusable, click → `OPEN_DETAIL`. `layoutId={layoutIds.card(id)}` so CR-03 and BN-01 can continue the element.
- `StageCardControls`: `Read` (`R`, `kbd` hint) and `Collect →` (`Enter`, `→`). Buttons below the card, 44 px; on mobile full-width row.
- `rarityBeats.ts`: given rarity returns `{ preDelay, dimStage, runHolo, flashTitle, sound }` per spec; applied by `StageCard` (stage dim via a `data-dim` attribute on Stage that lane A styles — **Request to SC-01 if missing**, or set a CSS var on `<main>`).
- Collect flight is **not** here (BN-01 owns the landing; the `layoutId` handoff makes the flight automatic when `StageCard` unmounts and `BinderSlot` mounts filled — verify in SC-02).
- Announce `card_revealed` with title + rarity via `useAnnouncer`.

## Acceptance criteria
- [ ] Playwright: `drawCard()` → `card-on-stage`, stage card visible with the correct title; `→` collects; last card shows `last_in_pack` copy before it is drawn.
- [ ] Rare card: a ≥ 300 ms delay before the front is visible (measure via `data-face` attribute timestamps in test mode); common has none.
- [ ] Keyboard-only run through a whole pack passes on desktop.
- [ ] Video `CR-02-draw.webm`, screenshots common/rare on stage; reviewer taste test ("describes a physical cause?").
- [ ] Reduced: draw is a crossfade; no translate.
