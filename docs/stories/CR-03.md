# CR-03 — Card detail overlay

**Phase** 2 · **Lane** C · **Size** M · **Depends on** CR-02

## Goal
The "read more" of the CV. Calm, readable, one key to leave. Spec: INTERACTION-SPEC §5.

## Owns
`src/scene/CardDetail.tsx`, `CardDetail.module.css`, `src/scene/useFocusTrap.ts`, `src/scene/Scrim.tsx`.

## Scope
- Mounts in `card-detail`; `cardId` = `stageCardId` or the binder-opened id (machine `detailCardId`).
- `layoutId={layoutIds.card(id)}` continues from the stage card (or binder slot) into the panel's card; `spring.card`.
- Layout: desktop two columns (card 1.15× left, text right, max 920 px); mobile stacked, card on top at 60 % width, text below; panel scrolls internally; page never scrolls; `max-height: 100dvh − 2·s-6`.
- `Scrim` dims stage 40 % (`dur.md`), click → `CLOSE_DETAIL`.
- `useFocusTrap`: traps Tab within panel, initial focus on the close button, restores focus to the trigger on close. `Esc` closes. `role="dialog"` `aria-modal` `aria-labelledby` title.
- Contains `Collect` too (hidden when opened from the binder for an already collected card); collecting from detail closes and lets the `layoutId` flight go to the binder.
- Links from `card.links` as ghost buttons; `mailto:` allowed.
- Reduced: fade.

## Acceptance criteria
- [ ] Playwright: open via click, via `R`, via binder slot (needs BN-01 — add this case in SC-02 instead; note it); close via `Esc`, `×`, scrim; focus restored (assert active element) on all 4 projects.
- [ ] Tab never leaves the panel (RTL loop of 20 tabs).
- [ ] Axe 0 violations with the dialog open.
- [ ] Long body (fixture with 1200 words) scrolls inside panel on mobile; page `scrollHeight === clientHeight`.
- [ ] Screenshots `CR-03-detail-*.png` incl. a holo card; reviewer approval.
