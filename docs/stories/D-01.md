# D-01 — Two NeoBrutalist style tiles

**Phase** 1 · **Size** M · **Depends on** F-06

## Goal
Two real-CSS directions for Pim to choose from, inside the DESIGN-BRIEF guardrails. This is the only story where the agent *designs*; afterwards the system is frozen.

## Owns
`src/dev/direction/Direction1.tsx`, `Direction2.tsx`, `direction1.module.css`, `direction2.module.css`, `src/dev/direction/shared.tsx`, `docs/design/direction-1.md`, `docs/design/direction-2.md`.

## Scope
Per direction, at `/dev/direction/1` and `/2`, each scoped with its own token overrides on a wrapper (so they don't leak):
- Palette swatches with proposed token values and contrast ratios printed.
- Type: display + text face, the fluid scale rendered.
- Button (default/hover/active/focus/disabled), Toggle, Badge, Chip.
- One **common** card and one **rare** card front at stage size, the card back, and the detail panel layout; a **placeholder-art** example.
- The sealed box and a pack (static).
- A desktop stage mock (1440) and a mobile mock (390) as side-by-side framed iframes of a static composition.
- A written rationale in `docs/design/direction-n.md`: mood in two sentences, why it reads professional, where restraint is applied, risks.

Directions must differ meaningfully (DESIGN-BRIEF §1 table). Both must pass the taste test (§2) and the contrast baseline (§6). Use the DESIGN-BRIEF's listed font candidates via `@fontsource`.

## Acceptance criteria
- [ ] Both routes render without console errors on desktop and mobile viewports.
- [ ] Every colour pairing used for text prints its contrast ratio and is ≥ 4.5:1.
- [ ] Screenshots `D-01-dir1-*.png`, `D-01-dir2-*.png` for both projects in `e2e/__screens__`.
- [ ] Reviewer agent confirms both directions satisfy the *fixed grammar* (borders, hard shadows, flat fills).
- [ ] Checkpoint `docs/checkpoints/M1-choose.md` summarising the two in one screen each and asking Pim to pick (and to note any swaps: "direction 1 with direction 2's type").

## Out of scope
Final tokens (D-02). Do not build primitives in `src/ui` yet.
