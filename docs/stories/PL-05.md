# PL-05 — Deploy

**Phase** 3 · **Size** S · **Depends on** F-01

## Goal
Every push to `main` deploys; Pim gets a URL to play on a phone.

## Owns
`.github/workflows/deploy.yml`, `vite.config.ts` (`base`), `public/404.html`, `docs/DEPLOY.md`.

## Scope
- GitHub Pages via `actions/deploy-pages`; `base` from `VITE_BASE` (default `/booster-cv/`, `/` when a custom domain is set); `VITE_SITE_URL` for OG absolute URLs.
- `404.html` = copy of `index.html` (SPA fallback; only `/` is a real route in prod anyway).
- Deploy job runs `npm run check` + `npm run e2e` first (reuse CI job via `workflow_call`).
- `docs/DEPLOY.md`: how to enable Pages, set the two variables, add a custom domain (CNAME) later, and how to deploy to Vercel/Netlify instead in 5 lines.

## Acceptance criteria
- [ ] A push to `main` publishes; URL recorded in `docs/checkpoints/M3.md`.
- [ ] Assets load under the sub-path (no absolute `/assets` URLs — check `dist/index.html`).
- [ ] Fonts and sfx served with correct MIME and cache headers (Pages defaults are fine; verify not broken).
