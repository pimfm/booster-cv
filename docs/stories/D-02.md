# D-02 — Finalise tokens

**Phase** 1 · **Size** S · **Depends on** D-01 + Pim's choice recorded in `docs/checkpoints/M1-choose.md`

## Goal
The chosen direction becomes the system. From here on, nobody picks colours.

## Owns
`src/design/tokens.css`, `src/design/tokens.ts`, `src/design/fonts.ts`, `docs/design/tokens.md`, `src/content/placeholderArt.tsx` (the designed placeholder art element).

## Scope
- Fill every token in DESIGN-BRIEF §4 with final values; remove "provisional" header.
- Rarity treatments as tokens + a small `rarity.css` with the four border/mark recipes (DESIGN-BRIEF §5 item 1) and the holo band keyframe (band only; movement logic comes in CR-04).
- Pack tint ramp (`--tint-1..5`): five flat colours that all pass ≥ 3:1 against ink borders and keep text in ink legible on them.
- Placeholder art component: pack tint fill, large outlined initial of the title in the display face, `ART` corner label; accepts `title`, `tint`.
- `docs/design/tokens.md`: the final table with swatches (rendered in `/dev/kit` too) and the rule "request a token via PR Requests".
- Delete `/dev/direction/*` or keep behind a `?legacy` flag — your call; document it.

## Acceptance criteria
- [ ] `npm run check` passes; `lint-tokens` still green.
- [ ] A Vitest contrast test over `tokens.ts` pairs (`ink/paper`, `ink/tint-n`, `paper/accent-n` where text is used) ≥ 4.5:1 for text pairs, ≥ 3:1 for border pairs.
- [ ] Placeholder art screenshot approved by reviewer against the taste test.
- [ ] CHANGELOG entry tells Pim which fonts/colours were chosen.
