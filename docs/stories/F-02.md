# F-02 — Design skeleton

**Phase** 0 · **Size** S · **Depends on** F-01

## Goal
The *structure* of the design system exists so that every component built from now on uses tokens, even before the direction is chosen.

## Owns
`src/design/tokens.css`, `src/design/tokens.ts`, `src/design/motion.ts`, `src/design/reset.css`, `src/design/fonts.ts`, `src/design/useMotionPrefs.ts`, `src/design/README.md`.

## Scope
- `tokens.css`: every variable from DESIGN-BRIEF §4 with **neutral provisional values** (ink `#111`, paper `#f4f1ea`, accents grey-ish). Mark the file header: "values provisional until D-02".
- `tokens.ts`: typed mirror (`export const tokens = { ink: 'var(--ink)', … }`) plus `rarityToken(r)`, `tintToken(n)` helpers.
- `motion.ts`: exactly the exports in DESIGN-BRIEF §3 (`dur`, `ease`, `spring`, `hold`) and `reduced` variants; `holdDurationMs()` reads `window.__BOOSTER_HOLD_MS__` in non-production.
- `useMotionPrefs()`: returns `{ reduced: boolean, spring(name), dur(name) }` — the reduced path returns near-zero durations; components call this instead of `useReducedMotion` directly.
- `reset.css`: minimal modern reset; `body` gets `--paper` background, `--ink` colour, `--font-text`.
- Fluid type scale with `clamp()` for `--step--1 … --step-4`.
- `README.md` in the folder: one page on how to use tokens from CSS Modules and from Framer Motion.

## Acceptance criteria
- [ ] No component in the repo uses a raw colour/duration after this story (grep in CI via an ESLint `no-restricted-syntax` rule or a small script `scripts/lint-tokens.mjs` that fails on `#[0-9a-f]{3,6}` and `\d+ms` outside `src/design/`).
- [ ] `useMotionPrefs` unit test: with `matchMedia` reduce → `reduced === true`, `spring('card')` returns `{ duration: 0.01 }`.
- [ ] `holdDurationMs()` returns override in test mode and 900 otherwise.
- [ ] Fonts self-hosted via `@fontsource`; no external font requests in the network log.

## Tests
`motion.test.ts`, `useMotionPrefs.test.tsx`, `lint-tokens` wired into `npm run check`.

## Out of scope
Final values (D-02), primitives (D-03).
