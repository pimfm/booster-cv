# CT-05 — Pim's content pass (human story)

**Phase** 4 · **Size** L · **Depends on** CT-01, CT-02 · **Owner: Pim** (an agent may assist with NL/EN proofreading only when asked)

## Goal
Real cards, real art where available, real contact details.

## Owns
`content/**`.

## Steps
1. Fill `docs/CONTENT-WORKSHOP.md` §1–§2 (goals, packs). Commit.
2. Draft 20–28 cards in the §4 grid (plain text, both languages). Commit as `docs/content-drafts.md` (gitignored if you prefer).
3. `content:new` per card; paste; set rarity/stats/tags. Keep `/dev/cards` open.
4. `content:stats` until the rarity distribution matches §3 roughly and no errors remain.
5. Art: add what you have; leave the rest as placeholders deliberately.
6. `meta.ts`: name, set name, tagline, contact, OG texts; `contentVersion` as needed.
7. Proofread NL and EN separately, out loud (§8 checklist).
8. Optional: ask an agent for a proofreading pass with the instruction "do not change meaning or jokes; flag, don't rewrite".

## Acceptance criteria
- [ ] `npm run content:check` clean (warnings allowed, listed in the PR).
- [ ] No placeholder copy remains (`content:check --no-placeholders` flag added by CT-01? — if not, grep for "Placeholder").
- [ ] Contact details verified by sending yourself the `mailto:`.
- [ ] Checkpoint `docs/checkpoints/M4.md`: screenshots of the gallery, open questions for QA.
