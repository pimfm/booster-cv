# CR-01 — Card component

**Phase** 2 · **Lane** C · **Size** L · **Depends on** D-03

## Goal
A card that is beautiful at thumbnail, stage and detail sizes, in both locales, for all four rarities, with or without art. Purely presentational; no machine access. Spec: DESIGN-BRIEF §5.

## Owns
`src/scene/Card.tsx`, `Card.module.css`, `src/scene/CardFront.tsx`, `CardBack.tsx`, `CardArt.tsx`, `CardStats.tsx`, `CardTitleBar.tsx`, `src/scene/cardSizes.ts`, `src/scene/markdown.tsx` (tiny renderer: paragraphs, bold, lists — no deps).

## Scope
- `Card` props: `card`, `locale`, `size: 'slot' | 'stage' | 'detail'`, `face: 'front' | 'back'`, `pack` (for tint/type line), `number` (global), `total`, `interactive?`.
- Anatomy per DESIGN-BRIEF §5; the 5:7 ratio is enforced with `aspect-ratio`; text scales with container (`container-type: inline-size` + `cqw` units) so one component serves all sizes.
- Rarity: border recipe + `Badge` mark; holo band element present but static (CR-04 animates).
- `CardArt`: `art` string → `<img loading="lazy" decoding="async">` (CT-03 adds variants); `null` → `PlaceholderArt` from D-02.
- `CardStats`: ≤ 4 `SegmentBar`s; hidden at `slot` size; labels localised.
- `CardBack`: single design per brief.
- Long titles: `title` ≤ 28 chars is enforced by content:check; still clamp to 2 lines with `text-wrap: balance`.
- Detail size shows `body` via `markdown.tsx` and `links` as ghost buttons (`rel="noopener"`).

## Acceptance criteria
- [ ] Storybook-like page section in `/dev/kit` → "Cards": all rarities × {art, placeholder} × {en, nl} × three sizes. (Owned here: `src/dev/kit/Cards.tsx`.)
- [ ] RTL: renders title/flavour/stats for both locales; `art=null` renders placeholder with the title's initial; markdown renderer tests (bold, list, paragraphs, escaping `<`).
- [ ] Text never overflows at `slot` 72 px wide, `stage` 260–360 px, `detail` 420 px (Playwright screenshot + `scrollWidth <= clientWidth` assertions).
- [ ] Axe 0 violations on the Cards kit section.
- [ ] Reviewer approval `CR-01-cards-*.png` — specifically: the placeholder must look intentional.
