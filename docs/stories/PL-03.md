# PL-03 — Sound

**Phase** 3 · **Size** M · **Depends on** SC-02

## Goal
Five tiny sounds that make the physics audible, off by default, never necessary. Spec: INTERACTION-SPEC §12.

## Owns
`src/platform/audio/AudioProvider.tsx`, `bus.ts` (or adopt `src/platform/events.ts` from BX-02 and re-export), `useSound.ts`, `samples.ts`, `public/sfx/*.webm|mp3`, `src/chrome/SoundToggle.tsx`, `docs/design/sound.md`.

## Scope
- Source samples: generate or select **CC0** samples; document provenance in `docs/design/sound.md`. Trim to spec lengths; normalise to −14 LUFS-ish; export `.webm` (opus) + `.mp3` fallback; total ≤ 60 KB.
- `AudioProvider`: lazily creates `AudioContext` on first user gesture *after* the toggle is on; preloads/decode once; master gain 0.5; `play(name, { volume })`; respects `document.hidden` (no play).
- Event mapping from the bus: `hold:mark → tick (0.5)`, `box:open|pack:tear → tear`, `card:collected → slide`, `card:rare → rare`, `all:collected → done`. Emitters already exist in lanes; verify and add missing emits (list in PR as small edits allowed by SC-02 ownership transfer — note in PR).
- `SoundToggle`: `IconButton` pressed state, key `M`, persisted via PL-02's `sound` field (Request if PL-02 lacks it — it's in PL-02's scope).
- Reduced motion does not affect sound. `prefers-reduced-transparency` irrelevant.

## Acceptance criteria
- [ ] No `AudioContext` created before toggle on (Playwright: `window.AudioContext` wrapped in init script to count constructions).
- [ ] With sound on, `tearPack()` triggers exactly one `tear` play (instrument `play` in test mode via `window.__SFX_LOG__`).
- [ ] Toggle state persists across reload; icon reflects state; `aria-pressed` correct.
- [ ] `docs/design/sound.md` lists each sample with licence and source.
- [ ] Pim listens and approves the set (checkpoint note in `docs/checkpoints/M3.md`).
