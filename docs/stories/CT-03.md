# CT-03 — Art pipeline

**Phase** 4 · **Size** S · **Depends on** CR-01

## Goal
Pim drops a single image per card; the build does the rest.

## Owns
`src/content/art.ts`, `vite.config.ts` image plugin section (`vite-imagetools` or `sharp` build step in `scripts/art-build.mjs`), `src/scene/CardArt.tsx` (srcset part), `docs/CONTENT-AUTHORING.md` §5.

## Scope
- Import art via glob with query `?w=400;800&format=webp&as=srcset` (imagetools) → `CardArt` renders `srcset` + `sizes` per card size; `loading="lazy"` except the first pack's first card (`fetchpriority="high"` once revealing starts is overkill — keep lazy).
- `artAlt` required when art is set (already in schema); `alt=""` for placeholder.
- Ratio check already in `content:check`; add a build-time warning for files > 600 KB source.
- Document: formats, sizing, where files go, how placeholders behave.

## Acceptance criteria
- [ ] Build output contains two widths per art file; `CardArt` picks the small one at slot size (Playwright `currentSrc` assertion).
- [ ] A 3:2 image fails `content:check` with the ratio message.
- [ ] Lighthouse-free check: total transferred on first load (sealed) excludes all art (network log assertion).
