# BN-03 — Mobile binder sheet

**Phase** 2 · **Lane** D · **Size** M · **Depends on** BN-01

## Goal
On a phone the full binder is one thumb-pull away and never in the way.

## Owns
`src/binder/BinderSheet.tsx`, `BinderSheet.module.css`, `src/binder/useSheetDrag.ts`.

## Scope
- Handle on the strip (`▲ Binder`, strings.binder_open) and key `B` toggle; drag-up gesture on the strip opens; drag-down or `Esc` or scrim tap closes.
- Sheet: 50 dvh (expandable to 90 dvh by a second pull), paper fill, `--border-2` top, hard shadow upward; contains Progress + the grouped grid from BN-01 (reuse `BinderGroup`), 4 columns.
- Motion: `spring.pack` for the sheet; drag uses `dragConstraints` + `dragElastic 0.05`; reduced → instant.
- Focus: moving focus into the sheet on open, back to the handle on close; `aria-expanded` on the handle.
- Opening a card's detail from the sheet closes the sheet first (or layers the dialog above; pick one, document; dialog above is simpler and allowed).

## Acceptance criteria
- [ ] Playwright mobile: handle tap opens; `Esc` closes; drag up opens; focus handling asserted.
- [ ] Sheet never covers the header; scrim present; stage not interactive while open.
- [ ] Desktop: the sheet code is not mounted (assert absence) — the rail is used.
- [ ] Screenshots `BN-03-sheet-mobile-webkit.png`; reviewer approval.
