# CR-04 — Holo band and swipe-to-collect

**Phase** 2 · **Lane** C · **Size** S · **Depends on** CR-02

## Goal
The one permitted "sparkle" — a sharp light band — and the one mobile gesture. Spec: INTERACTION-SPEC §4 rarity beats (rare/holo), mobile swipe.

## Owns
`src/scene/HoloBand.tsx`, `src/scene/useHoloPointer.ts`, `src/scene/useSwipeCollect.ts`.

## Scope
- `HoloBand`: absolutely positioned 1-px-sharp band (two hard colour stops, 18 % of width, 20° rotation) clipped to the card; `x` is a motion value 0–100 %.
- Rare: on land, run once left → right in `dur.xl`, `ease.inOut`.
- Holo: on land run once; afterwards `x` follows `pointermove` (desktop) / `touchmove` (mobile) relative to the card's left edge, with `useSpring(x, spring.settle)` for smoothing; on leave, eases back to 50 %. On keyboard focus: one run. No 3D, no filter, no blend modes heavier than `mix-blend-mode: soft-light` (allowed once here).
- `useSwipeCollect` (mobile only, `pointer: coarse`): drag the stage card horizontally; `x` follows finger with 0.6 damping; release past −80 px → `COLLECT_CARD`; else spring back (`spring.card`). Vertical movement > 10 px first cancels (scroll intent). Right swipe clamps at +16 px.
- Reduced: band runs as a 0.01 s opacity blink (effectively static highlight) and swipe still works without the follow animation (card jumps).

## Acceptance criteria
- [ ] Playwright mobile: swipe left collects; swipe left 40 px does not; vertical drag does nothing.
- [ ] Holo follows pointer (assert band `transform` changes between two `mouse.move`s) on desktop; rare does not follow.
- [ ] 60 fps budget: pointer handler does no React state updates (motion values only) — assert `StageCard` render count stable during 50 moves.
- [ ] Video `CR-04-holo.webm`; reviewer confirms it reads as "light on foil", not "rainbow".
