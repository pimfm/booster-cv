# QA-03 — Performance

**Phase** 5 · **Size** S · **Depends on** Milestone M3

## Goal
Fast on a phone on store Wi-Fi.

## Owns
`vite.config.ts` (chunks), lazy imports in `src/app/routes.tsx`, `scripts/bundle-budget.mjs`, `docs/design/perf.md`.

## Scope
- Budget: initial JS ≤ 120 KB gzipped (React + Framer `domAnimation` + app), CSS ≤ 20 KB, fonts ≤ 2 files × ≤ 40 KB (subset latin + latin-ext via fontsource variants), sfx not loaded until toggled, art lazy.
- `scripts/bundle-budget.mjs` reads `dist/` and fails CI over budget.
- Verify `LazyMotion strict` (no full `motion` import), `CardDetail`/`BinderSheet`/`ShortcutsPopover` lazy-loaded, no duplicate React.
- Web vitals in Playwright (`web-vitals` injected): LCP < 2.0 s on throttled "Fast 3G", CLS < 0.02 across the loop, INP < 200 ms for draw/collect on 4× CPU.
- Preload the display font; `font-display: swap` with size-adjust to avoid CLS.

## Acceptance criteria
- [ ] Budget script in CI, green.
- [ ] Vitals assertions in `e2e/perf.spec.ts`, green on `mobile-chromium` throttled.
- [ ] `docs/design/perf.md` with the numbers.
