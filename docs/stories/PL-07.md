# PL-07 — Accessibility pass

**Phase** 3 · **Size** M · **Depends on** SC-02, PL-01

## Goal
A screen-reader user and a keyboard-only user get the same story, in order, without surprises. Spec: INTERACTION-SPEC §10, DESIGN-BRIEF §6.

## Owns
`src/chrome/ShortcutsPopover.tsx`, `src/chrome/LiveRegion.tsx`, `src/chrome/announcements.ts`, `src/app/useGlobalShortcuts.ts`, `docs/design/a11y.md`.

## Scope
- Global shortcuts hook (`R`, `B`, `M`, `L`, `?`, `Esc`, arrows) with correct scoping (disabled while typing in nothing — there are no inputs — but disabled while detail is open except `Esc`/`R`), listed in a `?` popover (dialog, `Kbd` components, strings).
- Announcement map review: one message per transition, no double announcements, titles read in the current locale; `hold` start → "Opening…", cancel → not-yet copy; rare → includes rarity word.
- Focus order audit per phase; `aria-hidden` on decorative pieces (wrap halves, lid, tear strip, band); `inert` on the stage when detail/sheet open.
- Contrast audit of the final tokens in situ (Axe + manual on tint backgrounds).
- Reduced-motion audit: every motion path checked under the fixture; document any remaining translation (should be none).
- `docs/design/a11y.md`: what was checked, with what, and known limits.

## Acceptance criteria
- [ ] Axe 0 violations in every phase on both projects (extend SC-02's spec).
- [ ] Keyboard-only full journey on desktop with `Tab` count per phase recorded (no traps, no dead ends).
- [ ] VoiceOver (iOS, Pim) and NVDA or VoiceOver macOS (agent, via Playwright's accessibility snapshot as proxy) checked; notes in a11y.md.
- [ ] `?` popover lists every shortcut from INTERACTION-SPEC §10 (RTL test compares against a constant).
