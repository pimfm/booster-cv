# F-03 — Content schema, loader, placeholders

**Phase** 0 · **Size** M · **Depends on** F-01

## Goal
Pim's authoring surface exists and is validated. The app can run on a designed placeholder set from day one.

## Owns
`src/content/schema.ts`, `src/content/define.ts`, `src/content/loader.ts`, `src/content/placeholders.ts`, `src/content/types.ts`, `content/**` (initial files), `scripts/content-check.mjs`.

## Scope
- Implement the schema from CONTENT-AUTHORING §2 with zod; export inferred TS types.
- `defineCard`, `definePack`, `defineMeta`, `defineStrings` identity helpers with full typing.
- `loader.ts`: `import.meta.glob('/content/cards/*.ts', { eager: true })` → validated `ContentBundle { packs, cards (Map), meta, strings }`. Throws a readable aggregated error in dev; in production, falls back to placeholders for a single invalid card and logs.
- `content/` initial files: `packs.ts` with 4 packs (`personality`, `craft`, `table`, `track-record`), **16 placeholder cards** with clearly placeholder yet tasteful copy ("Placeholder trait — replace me", with varied rarities incl. 2 rare, 1 holo), `strings.en.ts` / `strings.nl.ts` with every key referenced in INTERACTION-SPEC, `meta.ts` with placeholder name/contact and `contentVersion: 1`.
- `content/cards/_template.ts` (not globbed: underscore prefix excluded).
- `scripts/content-check.mjs` runs the zod validation plus the rules in CONTENT-AUTHORING §2 (lengths, art existence + ratio via `sharp` or `image-size`, rarity budget warning, `.ids.lock` comparison — write the lock on `--write-lock`). Exit code 1 on error, 0 with warnings.
- Selectors: `getPack(id)`, `getCard(id)`, `cardsInPack(id)`, `totalCards()`, `cardNumber(id)` (global 1-based number by pack order).

## Acceptance criteria
- [ ] `npm run content:check` passes on the placeholder set and fails with a precise message (file, field, rule) for each fixture in `src/content/__fixtures__/invalid/*`.
- [ ] Removing a card id from a pack without bumping `contentVersion` fails the check with a hint.
- [ ] Both locales type-check against each other (`strings.nl.ts` satisfies `typeof en` keys).
- [ ] Placeholder copy contains no lorem ipsum and reads as intentional.
- [ ] Loader unit tests cover: happy path, duplicate id across packs, missing locale, card referenced but missing.

## Out of scope
Scaffolder CLI (CT-01), gallery (CT-02), art variants (CT-03).
