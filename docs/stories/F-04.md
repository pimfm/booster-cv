# F-04 — Experience state machine

**Phase** 0 · **Size** M · **Depends on** F-03

## Goal
The single source of truth for the experience, as a pure, exhaustively tested reducer. This is the contract all lanes build against (PLAN §5).

## Owns
`src/machine/types.ts`, `src/machine/reducer.ts`, `src/machine/hold.ts`, `src/machine/selectors.ts`, `src/machine/ExperienceProvider.tsx`, `src/machine/useExperience.ts`, `src/machine/index.ts`.

## Scope
- Types exactly as in PLAN §5 (`Phase`, `ExperienceState`, `Action`); `initialState(bundle)`.
- `reducer(state, action, ctx)` where `ctx = { bundle, holdDurationMs, cancelReturnMs }`. Rules:
  - `HOLD_START` valid in `sealed` → `unwrapping`, in `pack-focused` → `pack-tearing`; otherwise ignored.
  - `HOLD_TICK` advances `holdProgress` via `advanceHold`; when it reaches 1 the reducer emits the completion itself (sets `phase` to `box-open` / `pack-torn` and fills `queue` from the pack's authored card order). No separate `TEAR_COMPLETE` dispatch is required from UI, but the action exists for tests and reduced-motion.
  - `HOLD_END` before 1 → back to `sealed`/`pack-focused`, `holdProgress` keeps its value and relaxes through subsequent `HOLD_TICK`s until 0 (so the UI can animate the relax from the machine) — model this with a `holdDirection: 'up' | 'down' | 'idle'` field.
  - `FOCUS_PACK` only for unopened packs in `box-open`. `UNFOCUS_PACK` from `pack-focused`.
  - `DRAW_CARD` in `revealing` pops `queue` → `stageCardId`, phase `card-on-stage`. `OPEN_DETAIL`/`CLOSE_DETAIL` toggle `card-detail` (also allowed from binder with a `cardId` payload: add `OPEN_DETAIL { cardId? }`; from binder it returns to the previous phase on close — store `returnPhase`).
  - `COLLECT_CARD` pushes to `collected`, clears stage; `queue` empty → `pack-complete` (+ `openedPacks`), else `revealing`. `DISMISS_PACK` → `box-open` or `all-collected` when all packs opened.
  - `seenRare` set when a rare/holo is drawn the first time.
  - `RESET` → `resetting` → `initialState` on the next `HOLD_TICK`/`RESET_DONE` (add `RESET_DONE`).
  - `HYDRATE` replaces `collected`/`openedPacks` and derives phase (`box-open` if any pack opened, `all-collected` if all, else `sealed`).
- `hold.ts` per INTERACTION-SPEC §11.
- `selectors.ts`: `isHolding`, `visiblePacks`, `remainingInPack`, `progressByPack`, `isComplete`, `stageCard`, `holdVisual(p)` returning the derived numbers from INTERACTION-SPEC §1/§3 (scale, skew, seam opacity) so components share one mapping.
- `ExperienceProvider` with `useReducer`, a `rAF` hold loop that dispatches `HOLD_TICK` while `holdDirection !== 'idle'`, and `useExperience()` returning `{ state, dispatch, select }`. Listens to `visibilitychange`/`blur` to dispatch `HOLD_END`.

## Acceptance criteria
- [ ] 100 % branch coverage on `reducer.ts` and `hold.ts` (vitest `--coverage` threshold in config for these two files).
- [ ] A table-driven test asserts that every `(phase, action)` pair not listed as valid leaves state unchanged (referential equality).
- [ ] `holdCurve` monotonic, `holdCurve(0)=0`, `holdCurve(1)=1`, `crossedMark` fires each mark exactly once per hold.
- [ ] A scripted full run (sealed → all-collected) over the placeholder bundle in one test yields `collected.length === totalCards()` and `openedPacks` in the order opened.
- [ ] Provider test: holding for `holdDurationMs` via fake timers + rAF mock opens the box.
- [ ] `docs/INTERACTION-SPEC.md` matches; any deviation documented in the PR and spec updated.

## Out of scope
Any rendering. Persistence (PL-02) only consumes `HYDRATE`.
