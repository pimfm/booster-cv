# F-06 — App shell with slots

**Phase** 0 · **Size** S · **Depends on** F-02, F-04

## Goal
The composition skeleton from AGENT-WORKFLOW §4, so lanes can work in isolation and the dev routes exist.

## Owns
`src/app/App.tsx`, `src/app/main.tsx`, `src/app/routes.tsx`, `src/app/Providers.tsx`, `src/scene/layoutIds.ts`, stub components: `src/scene/Stage.tsx`, `Box.tsx`, `PackShelf.tsx`, `RevealStack.tsx`, `StageCard.tsx`, `CardDetail.tsx`, `src/binder/Binder.tsx`, `src/chrome/Header.tsx`, `src/chrome/LiveRegion.tsx`, `src/dev/DevIndex.tsx`.

## Scope
- Routing: tiny hash-less router (or `react-router` if preferred; keep it light): `/` → experience, `/dev` → index of dev pages, `/dev/kit`, `/dev/cards`, `/dev/direction/:n`, `/dev/og` (all return "not built yet" placeholders). Dev routes tree-shaken out in production via `import.meta.env.DEV` guard.
- `Providers`: `LazyMotion features={domAnimation} strict`, `ExperienceProvider`, placeholders for Locale/Audio/Persistence providers (identity wrappers to be filled by PL-01/02/03 **without touching App.tsx**: each provider lives in its own file exporting a component; `Providers.tsx` already imports them).
- `<main data-phase={phase} data-animating>` wrapper; `data-animating` driven by a small `useAnimationActivity()` hook counting Framer `onAnimationStart/Complete` via context (lanes call `useAnimationTracking()` in their motion components).
- Stub components render a visible outlined box with their name **only in dev** and a minimal functional stand-in: `Box` stub is a button with `onPointerDown → HOLD_START`, `onPointerUp → HOLD_END` so F-05's spec works end-to-end; `PackShelf` stub lists pack names as buttons dispatching `FOCUS_PACK`; etc. Just enough to drive the machine from the UI.
- `layoutIds.ts` per AGENT-WORKFLOW §4.
- `LiveRegion`: `aria-live="polite"` div subscribed to a `useAnnouncer()` context; message set by machine transitions (map in `src/chrome/announcements.ts` from `strings`).

## Acceptance criteria
- [ ] Full loop drivable through the stubs with mouse and keyboard; `phase()` reaches `all-collected`.
- [ ] Production build contains no `/dev` code (check `dist` for the string "DevIndex").
- [ ] LiveRegion announces at least `hold_box`, `pick_pack`, `card_revealed`, `all_done` (RTL test).
- [ ] Checkpoint file `docs/checkpoints/M0.md` written: how to run, what works, open questions.

## Out of scope
Any real visuals.
