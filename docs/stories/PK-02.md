# PK-02 — Focus a pack

**Phase** 2 · **Lane** B · **Size** S · **Depends on** PK-01

## Goal
Selecting a pack brings it to the centre with weight; leaving is one key away. Spec: INTERACTION-SPEC §2 "Select".

## Owns
`src/scene/Pack.tsx` (focused state), `src/scene/FocusedPack.tsx`, `src/scene/BackToBox.tsx`.

## Scope
- `layoutId={layoutIds.pack(id)}` shared between shelf `Pack` and `FocusedPack`; `spring.pack`; target scale 1.35 (mobile 1.2, capped so the pack never exceeds 62 vh).
- Others: slide back 24 px, scale 0.92, opacity 0.6 (`dur.md`, `ease.inOut`).
- `BackToBox`: ghost button top-left of stage, strings.back_to_box, `Esc` handler (only when no detail open). Dispatches `UNFOCUS_PACK`.
- Focus management: focus moves to the focused pack (it is the hold target); on unfocus, focus returns to that pack on the shelf.
- Reduced motion: crossfade instead of travel.

## Acceptance criteria
- [ ] Playwright: click pack → phase `pack-focused`, focused element is the pack; `Esc` returns to `box-open` with focus restored to the same shelf pack (assert `document.activeElement` text).
- [ ] Focused pack never overflows the stage at 390×660 and 1440×900.
- [ ] Reduced: no `transform` change on the pack between states (assert computed transform `none` / matrix identity after settle).
- [ ] Screenshot `PK-02-focused-*.png`.
