# PK-01 — Pack shelf and Pack visual

**Phase** 2 · **Lane** B · **Size** M · **Depends on** D-03

## Goal
Packs that look like packs, laid out so a thumb can reach them, with a clear opened state. Spec: INTERACTION-SPEC §2.

## Owns
`src/scene/PackShelf.tsx`, `PackShelf.module.css`, `src/scene/Pack.tsx`, `Pack.module.css`, `src/scene/PackCrimp.tsx`, `src/scene/packVariants.ts`.

## Scope
- `Pack`: `Frame` with pack tint, crimped top edge (`PackCrimp`: an SVG zigzag strip, 6 px teeth, ink stroke, rendered as the top border), name in display face, blurb in `--step--1`, `n cards`. Props: `pack`, `state: 'sealed' | 'opened' | 'focused'`, `index`.
- Opened: flattened look — height 60 %, reduced contrast, a torn top (the crimp with a ragged path), label strings.opened with a checked square; `aria-disabled`.
- `PackShelf`: row on desktop; 2-column grid on mobile with a horizontal scroll fallback for > 4 packs; sits on the tray line from the box (lane A exposes `--tray-height` on Stage; use it). Roving `tabindex`, arrow keys move focus (both axes on mobile grid), Home/End.
- Enter variants `packVariants.enter(index)` for BX-02's rise (translateY 24 → 0, opacity, `spring.pack`, delay `index * 0.07`).
- Hover lift on `pointer: fine`; focus ring.
- Renders only in phases `box-open`, `pack-focused`, `pack-tearing` (others return null; `pack-torn` and later hide the shelf per spec — the focused pack is still rendered by `Pack` with `state='focused'` in PK-02).

## Acceptance criteria
- [ ] Shelf renders all packs from content with correct tints and counts (RTL).
- [ ] Arrow-key navigation covers all sealed packs and skips opened ones; Enter dispatches `FOCUS_PACK` (RTL with user-event).
- [ ] Mobile: all packs reachable without scrolling for ≤ 4 packs at 390×660; targets ≥ 44 px.
- [ ] Screenshots `PK-01-shelf-*.png` (with one pack opened, use `HYDRATE` in a dev query `?state=` provided by F-06… if not available, add `?debugOpened=personality` handling in PackShelf **dev only**).
- [ ] Reviewer approval on the crimp and the opened look.
