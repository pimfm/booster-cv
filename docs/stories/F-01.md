# F-01 — Scaffold

**Phase** 0 · **Size** M · **Depends on** — · **Lane** serial

## Goal
A runnable, linted, typed, tested repo so that every later story starts from the same base.

## Owns
Repo root (`package.json`, `vite.config.ts`, `tsconfig*.json`, `.eslintrc.cjs`, `.prettierrc`, `index.html`), `.github/workflows/ci.yml`, `vitest.config.ts`, `playwright.config.ts` (skeleton; F-05 fills projects), `README.md`, `docs/CHANGELOG.md`, `docs/LATER.md`.

## Scope
- `npm create vite` React + TS, then: strict TS (`noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`), path alias `@/` → `src/`.
- Dependencies: `react`, `react-dom`, `framer-motion`, `zod`, `@fontsource/*` (placeholder fonts until D-02), `lucide-react`.
- Dev: `vitest`, `@testing-library/react`, `@testing-library/user-event`, `jsdom`, `@playwright/test`, `eslint` (+ `typescript-eslint`, `react-hooks`, `jsx-a11y`), `prettier`.
- Scripts exactly as listed in `CLAUDE.md` (stubs allowed for `content:*`, `og:render` that print "not implemented (F-03/PL-04)" and exit 0).
- `npm run check` = `tsc --noEmit && eslint . && vitest run && npm run content:check`.
- CI: on PR and push to `main`: install, `npm run check`, `npx playwright install --with-deps`, `npm run e2e`. Cache node_modules and Playwright browsers.
- `README.md`: 10 lines: what, how to run, link to docs.

## Acceptance criteria
- [ ] `npm run dev` serves a page with text "booster-cv" and no console errors.
- [ ] `npm run check` passes on a clean clone.
- [ ] `npm run e2e` runs one trivial spec (page title) on chromium and passes.
- [ ] CI workflow green on the PR.
- [ ] ESLint flags `jsx-a11y` violations and `react-hooks/exhaustive-deps`.
- [ ] `docs/CHANGELOG.md` exists with a heading and the F-01 entry.

## Tests
- `src/smoke.test.tsx`: renders `<App />`.
- `e2e/smoke.spec.ts`: title contains "Pim".

## Out of scope
Design tokens (F-02), Playwright projects (F-05), deploy workflow (PL-05).
