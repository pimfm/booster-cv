# Checkpoint M0 — foundation (after F-06)

## How to run

```sh
npm install
npm run dev            # http://localhost:5173 — the experience; /dev lists dev pages
npm run check          # typecheck + lint + vitest + content:check
npm run e2e            # Playwright (see e2e/README.md for sandbox env vars)
npm run build && npm run preview
```

Useful URLs: `/?lang=nl` (Dutch), `/?fresh` (used by tests; PL-02 will skip hydration on it).

## What works

- The whole loop is drivable with **unstyled stand-ins**: hold the box (pointer, Space or
  Enter; a single press under reduced motion) → pick a pack → hold to tear → draw → read /
  collect → "Pack done." (900 ms or any key/press) → … → the contact card is drawn by
  itself → `all-collected`, binder `17 / 17`. Reset from the header (no confirm yet).
- Early release goes back and shows "Not yet — keep holding." for 1.6 s.
- EN/NL toggle in the header; `?lang=`, a stored choice and the browser language decide
  the first locale; `<html lang>` follows.
- One polite live region announces the transitions (hold, opening, pick a pack, card
  revealed with title and rarity, pack done, all done, not yet).
- Layout grid: header / stage / binder (right rail ≥ 900 px, bottom strip below), `100dvh`,
  no page scroll.
- `main[data-phase]` and `main[data-animating]` for tests; the Playwright `app` fixture
  drives every step on desktop and mobile Chromium, with and without reduced motion.
- Production build contains no `/src/dev` code (checked on `dist/assets/*.js`).

## What is a stand-in

Every component in `src/scene`, `src/binder/Binder.tsx` and `src/chrome/Header.tsx` is an
F-06 stand-in: outlined boxes, no motion, no art. Not there yet: the reveal stack's 400 ms
input lock, focus trap and focus return in the detail, roving focus on the shelf, the
reset confirm, sound, persistence (PersistenceProvider and AudioProvider are identity
wrappers for PL-02 / PL-03).
